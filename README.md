# Easier Crafting:
The definitive unofficial port of [EasierCrafting](https://modrinth.com/mod/easiercrafting), completely rewritten for Minecraft 1.21+ and modern performance.

Easier Crafting removes the friction from your survival workflow by displaying exactly what you can craft with the materials currently in your pockets. No ghost items, no complex GUIs—just straightforward, one-click crafting.

## ✨ Key Features
Smart Recipe List: Automatically displays all recipes you can currently craft based on your inventory.

Quick Crafting: **Left-Click**: Crafts the item once immediately.

Shift-Click: Automatically crafts the item as many times as possible (up to a full stack or until you run out of ingredients).

Advanced Search Bar: Search by item name (full or partial) in English or your local language. You can set to show all recipes when searching. If you're missing ingredients, the item will have a red background.

Ingredient Tooltips: Hover over a item to see exactly which materials you need/ are missing.

Config: Includes a detailed configuration screen with multi-language support so you can tune the mod to your playstyle. (powered by cloth config)

## 📦 Supported Inventories
The mod integrates seamlessly with the most common workbenches:

Crafting Table (3x3 grid)

Player Inventory (2x2 grid)

Stonecutter (Instant recipe selection)

Furnaces (Including Blast Furnaces and Smokers)

## 📜 Version Support & History
Minecraft 1.21.2 - 1.21.8: These are the current focus of development. Due to significant internal changes in how Mojang handles recipes in 1.21.2+, the recipe system has been completely rewritten.

Minecraft 1.21 - 1.21.1: This version is a fork of taoge407's work [github page](https://github.com/taoge407/EasierCrafting-Reloaded), featuring additional improvements and bug fixes. Support for these versions is now limited to major bug fixes only.

## 🛠️ State of the Mod
This mod is currently in active development.

Rewritten Logic: Because of the 1.21.2 recipe overhaul, some older features are still being ported to the newer versions. Most of the features are restored currently. Newer versions are considered testing builds and may contain bugs. Your feedback is essential!
